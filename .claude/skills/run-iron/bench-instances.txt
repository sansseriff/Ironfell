# The instance-cache benchmark (plans/specs/instance-cache.md phase 0): what
# component instances and a large group's drag cost per frame.
#
#   Meters: `?meters=100` adds 100 dial meters from the standard library (their
#   definition given 60 tick marks, so a face is worth baking) and a slider
#   driving the first one's `in`. Idle; scrubbing the slider (one needle and
#   readout change), twice: the first scrub bakes the view's first tiles, the
#   second should bake none; a pan. The `eval` lines print the raster groups
#   and tiles: equal instances share one face.
#   Prussia: the coat of arms (bench-large-svg.txt; copy it to
#   .agents/tmp/big.svg first) fitted in the Controls tab; a click selects
#   layer2, a double-click enters g93169 (38,901 nodes, nearly the whole
#   drawing), which is dragged and then undone.
#
# Build PROFILE=wasm-bench; run with
#   GPU=1 UNTHROTTLED=1 PANEL_PIXELS=physical SIZE=1600x1000@1 bun run drive.ts < bench-instances.txt
# and read the `measure` lines (changed_frame, display_list, encode, bake).
