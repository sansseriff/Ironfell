A guide in seven parts, plus a field guide

Iron's Document Spine

On September 18 the scene stopped living inside Bevy. It now lives in a document: a small Rust crate with stable ids, typed values, an operation log and undo. Bevy draws whatever the document says. This guide explains that change file by file and function by function, so you can open any file in the new system and know what it does and why it exists.

Written forYou. You know the project, the vision documents and the goals. Rust is the part you're less sure of, so the early parts go slowly on it.
How to read itIn order. Each part assumes the ones before it. Part 1 is the easiest on Rust, and it teaches the Rust the later parts use.
What it coversFive commits (42da7f2 to d4f2e37) plus the uncommitted work in your tree that finishes plan steps 6 and 7.

What the marks mean

Every code excerpt is copied from your working tree when the pages are built, with its real line numbers. Captions and file.rs:123-style references are vscode:// links: on your machine they open the file at that line. Highlighted bands inside a code block mark the lines the text is talking about.

Each excerpt carries a coloured chip naming the system it belongs to. The same eight colours are used throughout the guide:
